# Наш маршрут

Общий планировщик поездок для компании: места, голосование, карта, план по дням.

- Сайт: один файл `index.html`, без сборки. Хостинг: GitHub Pages.
- База: Firebase Firestore, проект `nash-marshrut`. Правила доступа: `firestore.rules`.
- Карта: Leaflet + OpenStreetMap/CARTO. Поиск мест: Nominatim (OpenStreetMap).

Локально: открыть `index.html` в браузере или `npx serve .`
